# blackscreen

A super simple HTML page that turns the entire screen black.

https://noxelwork.com/blackscreen

![screenshot](img/screenshot.png)

## Usage

1. Open the URL above or `index.html` in a browser
2. Click the `FULL SCREEN` button
3. The whole screen turns solid black (the button and mouse cursor are hidden)

To exit full screen, double-click or press `Esc`.

## Structure

Just a single `index.html` file
